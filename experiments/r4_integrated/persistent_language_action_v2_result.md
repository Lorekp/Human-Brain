## Same persistent learner and actual actions

Both neuronal controls start from the first broader session's final **online**
numerical model, experience count 46 and complete 453-slot tape. The disabled
copy has identical initial state and separate storage. Both continue episodic
writes; only current-session slow learning differs. Two new notes add 50 raw
bytes and two EOS symbols, reaching 505 occupied slots without reset, eviction
or task-selected retrieval.

The [selected reader](../../docs/research/request-conditioned-output-v1.md)
reconsiders every occupied address at each byte using the raw request and actual
earlier output. Fixed mixed threshold cells feed locally plastic byte/EOS
currents. Prefix/address and output synapses begin at zero; old numerical
parameters remain, with the previous codec held as a fixed prior. Changed
retrieval means initial generation parity with the old reader is not claimed.
The same reader supplies language answers and the action head's replacement
bytes. Learning uses direct local updates, with no backpropagation or separate
trained executor.

Each neuronal route receives 24 one-pass corrections: 74 raw target bytes,
24 EOS symbols and 36 action labels. The reference receives the same correction
opportunities. It restores only its actually observed 16 earlier documents and
12 edit demonstrations, then receives the same two notes and 12 new edit
demonstrations. Its explicit host retrieval/editing is reference computation.

The complete run records 216 responses, 144 real Python executions, 72
corrections and six append events across three routes. Every action is saved
before its target-bearing correction. Final snapshots retain both neuronal
models, tapes and experience for further continuation.

## Development consequence

The [saved learning review](../../docs/research/persistent-language-action-v2-learning-review.md)
finds that all 22 supported reading outputs are identical between neuronal
routes: 19 repeat a byte to the limit and three emit empty EOS. All 46 actual
online action payloads lack EOS, so every online splice is rejected. Two
first-attempt payloads show address switching without useful sequencing.
All 24 online reader corrections publish B/C/U, but teacher-prefix NLL is
higher than the held control; the local potential objective does not guarantee
mixture-NLL or free-generation improvement.

The [evaluation review](../../docs/research/persistent-language-action-v2-evaluation-review.md)
independently traces all 72 reference attempts to available history. It also
preserves failures on negation, two-note answer composition and contextual
formatting. Stronger retrieval/edit reuse is not general understanding.

The new mechanism permits request-conditioned construction and changing memory
addresses, but permission in the architecture is not demonstrated competence.
The [cost review](../../docs/research/persistent-language-action-v2-cost-review.md)
finds free-attempt processing dominates measured time. The
[selected next implementation](../../docs/research/active-path-output-learning-v1.md)
binds output correction to an actual failed event and reuses unchanged prefix
activity. It has not run or established an improvement. Do not repeat this now-exposed cohort until it fits,
turn its failures into automatic toy gates, or require perfection before further
broader exposure. The long-term Gemma and Opus comparisons remain unattempted.
