## What was lost

The [traceback](../../.pytest-tmp/persistent-language-action-v8.stderr) reports
`RecurrentContentSourceFeedback is not JSON serializable`. The
[failure receipt](../../.pytest-tmp/persistent-language-action-v8-run/failure.json)
places the error in journal encoding, after the first online source call returned
and its allocation, RNG and held-prior checks passed, but before any source row
was written or the next checkpoint committed.

That frozen first source is `N36`, before `A00-R`: 88 raw bytes plus EOS.
Source/control-flow evidence therefore implies **89 completed local source
offers**, 89 scan ticks and 267–356 stochastic draws. The range reflects three
compulsory draws per tick and an optional literal draw. Live factual occupancy
reached 1703 and controller/RNG publication occurred. These are explicitly
control-flow inferences: the actual symbol receipts, emitted choices, rewards,
update values, exact draw count and post-source hashes are unavailable.

The live source update was lost. No task prediction, answer correction, action
label or child execution followed, and the disabled and simple routes had not
observed this source. Zero durable source rows must not be reported as zero
attempted learning. Safe HEAD 0 remains, with
[intent 1 unresolved](../../.pytest-tmp/persistent-language-action-v8-run/checkpoints/intent-000000001.json);
the failed store is dirty and cannot silently resume that scientific stream.
