# Direct value-neuron credit return

Status: prospective; no cost or acquisition run. 2026-09-06.

The [selected writer-credit review](../../docs/research/local-memory-writer-credit-review.md)
and [primary-source derivation](../../docs/research/local-memory-writer-credit-sources.md)
select one integrated comparison after the query-credit return improved fit
without useful new-value or learned-writer advantage. The tested hypothesis is
that the existing value tags need their corresponding read-neuron errors instead
of a random mixture of context errors. Source/key binding and interference remain
competing explanations; this protocol selects no concurrent representation repair.

## Fixed candidate and immediate predecessor

Replace only the value-map learning signal with
`mean_context_signal[:, query_size:]`. Preserve the float64 sum/mean over all
three LMS teachers, the single checked upstream cast, existing value-tag transport
and final negative learning-rate update. Do not insert another tanh gain, beta,
query contraction, memory transpose, learning rate or output-count divisor.
Controller/key/strength broadcasts, repaired instantaneous query credit, LMS
output, recurrent self-path credit, finite checks and publication order stay fixed.

Tagged value eligibility equals the conditional real-arithmetic value-map
derivative over a fixed-slow-weight ingestion interval. The current architecture
has no value-to-writer/key feedback, making that particular partial derivative
well-defined. The claim does not extend to aggregate traces, controller/key/strength
credit, derivatives of discrete floating operations, earlier retired history,
whole-lesson transactions or convergence. Locality uses each synapse's existing
tag and its value neuron's read error; no host per-synapse oracle, BPTT or optimizer.

Use six ordered arms: `tagged`, `aggregate`, `writer_maps_frozen`, `frozen`,
`writes_disabled`, `current_tagged`. The first five use direct value credit.
The last uses the immediate predecessor at
`f195a36323a4450b40e454e6a0d0df11ba126626`: repaired query credit and random
value broadcast. Its complete learner source is archived explicitly for this
experiment and shares unchanged memory/LMS dependencies with source and trajectory
QA. It does not use the older d724 query-credit comparator. No runtime Git source
loading, production compatibility branch or mutable global patch is permitted.

Different rule metadata is intentional. No fitted endpoint, cost update or

interference challenge. There is no decay or later-teaching retention claim.

real Python executor, plus two separately counted motor demonstrations. That
host-authored matching schema does not establish a neuronal action policy.

The useful endpoint remains tagged 8/8 fit and 4/4 in every remaining stratum,
plus strict new-value action superiority over writer-frozen, fully frozen,
writes-disabled and immediate-predecessor tagged. Report tagged versus aggregate
separately. A smaller fit/loss improvement is descriptive, not qualification.
There is no automatic extra epoch, seed, rate or broadcast sweep. A useful result
returns to broader persistent raw-document/actions and learned action selection;
no protected gate follows from this narrow development result alone.
