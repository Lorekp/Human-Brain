## Fixed architecture and reference

Keep 64 writer neurons. Indices 0-31 have update fraction 0.5, 32-47 have 0.125,
and 48-63 have 0.03125. Every writer map still reads every neuron; recurrence is
fully connected. Query cells remain scalar 0.5. No rescaling, learned rates,
inverse-rate compensation, new activity/tag bank or altered document boundary
is introduced. Preserve the existing own-neuron eligibility with the matching
fraction in its immediate derivative and carry; omitted cross-neuron derivative
paths remain approximate. Query credit, direct value credit, other broadcasts
and the local LMS output are unchanged.

The general StreamingRateCell API accepts a fixed scalar or per-neuron vector.
Scalar 0.5 retains the original arithmetic and state keys; a vector is a copied,
non-learning buffer that follows model dtype/device and validates on restore.
This is an ordinary cell parameter, not a checkpoint migration or retired-model
production branch. The joined production default uses the fixed 64-cell bank;
other writer geometries require an explicit scalar/vector fraction. Small QA
fixtures use explicit scalar 0.5, not an implicit resized candidate bank.

Use the six existing arm names: tagged, aggregate, writer_maps_frozen, frozen,
writes_disabled and current_tagged. All first five use the same candidate bank.
The frozen-writer control therefore measures learning beyond that identical
temporal prior; replacing it with the old scalar writer would confound this
comparison. The experiment-only reference preserves the exact v3 learner class
from `86cc7232320cf4cef9337cf4f3b79a017bb55171`, using the reviewed ordinary
scalar-default cell dependency. No Git source is loaded during evaluation.
Reference dependency parity must be established against frozen old source in QA.

All six start fresh with seed 733, existing input-code/weight/broadcast random
draws, zero LMS weights and empty memory. No learned endpoint is warm-started.
Common initial tensor keys, values and dtypes must match exactly; the only
candidate-only tensor is `memory.controller.update_fraction`, exactly the fixed
64-vector. Candidate metadata explicitly differs from reference v3 metadata.
All candidate arms share their full initial tensor contents. The scalar reference
must reproduce the previous value-credit tagged trajectory, including 1,024
lesson receipts, final states and twenty outputs, after its own fresh run.
Candidate frozen-writer/frozen trajectories need not reproduce old scalar
memories. Frozen weights must remain unchanged, and writes-disabled must retain
the old query/output trajectory apart from declared configuration/state keys.
