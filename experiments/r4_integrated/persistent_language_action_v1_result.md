## What actually persisted and learned

Both neuronal routes start with identical trained numerical reader/action state
from the completed byte-coincidence comparison. The same two model instances
persist for the entire session. Only the online route publishes local updates;
episodic writes remain enabled in both. There is no backpropagation, separately
trained executor, answer lookup inside the neuronal route, or correction replay.

Sixteen notes append once to a shared tape: 437 raw bytes plus sixteen EOS slots,
453 occupied slots in a 512-slot capacity. No task selects a relevant document or
replaces the accumulated tape. The earlier comparison's separate task tapes are
discarded during initialization; their numerical learned parameters are retained.
Each issue starts with its declared files, and retries continue from actual
after-files. This is persistent model/memory evidence, not a continuous project
workspace across issue boundaries.

Each route is offered 24 corrections, once after the actual first response or
execution. Each neuronal route processes 104 reader byte/EOS offers and 36
action-head labels; the learning-disabled route publishes no slow updates.
All first-response acquisition blocks score zero for the neuronal routes. The
simple reference stores taught edit examples and uses generic trigram retrieval.
Its four delayed edit successes demonstrate example reuse, not new composition.

Delayed neuronal zero cannot establish forgetting: those eight cases were also
incorrect on their initial acquisition responses, and this protocol deliberately
does not add an immediate post-teacher replay. Acquisition, delayed performance
and demonstrated forgetting must remain distinct. Error text is recorded but
does not enter the current neuronal decoder. Changed file contents are its only
new input on recovery retries; acknowledgement alone supplies no recovery rule.

## Verification, resources and continuation

The run contains 216 responses/attempts, 144 actual Python executions, 72
correction-offer records and 39 shared-memory append records across three routes.
Independent review recomputes behavior grades, protected-file integrity, exact
raw edit application, phase counts, exposure and model/memory hash chains. It
does not replay the complete neuronal arithmetic or load a checkpoint.

The full process takes 18.9238 seconds; independent review takes 0.7384 seconds,
19.6621 seconds combined. Observed peak is 364.92 MiB. The watchdog samples owned
processes every 500 ms and can miss brief child processes; actual execution
receipts retain child PIDs. Different workloads prevent interpreting this as an
isolated speedup over the earlier toy comparison.

Initialization loads the authenticated 109,896,320-byte tensor container once,
including all five prior models and 360 tapes before discarding unused state.
