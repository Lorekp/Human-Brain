The single recommended integral optimization is an **exact fixed-neuron
tournament for factual address competition**. Keep every occupied address,
unchanged float32 input scores widened to float64, and contiguous fixed brackets.
Each pair uses the existing signed comparator and lower-index tie rule, followed
by explicit binary-gated relays that copy the winning potential and original
identity. Unpaired populations pass through a fixed relay. Count comparators,
gate inputs, copied potentials/identities, byes and actual arrays; host argmax,
sorting or an uncounted score selector would not implement this proposal.

There are `N-1` comparisons and `ceil(log2(N))` comparator stages, plus relay
stages, rather than the current two all-pairs threshold layers. Exact copied
potentials avoid arithmetic reconstruction and preserve later comparisons.
For these same saved factual populations, 4154272 candidate visits over 2642
decisions imply **4151630 tournament comparisons** instead of 3357755083 pairs
(808.78-fold fewer comparisons). Relays remain real additional work; this is
neither a latency ratio nor the original two-layer threshold circuit theorem.
All-address eligibility, emitted outputs, learning equations and model state
must remain unchanged; trace/work schemas must honestly describe the new circuit.
Ordinary parity checks should cover arbitrary occupied counts, ties, finite
float32 extremes and copied winner identity/potential. No kernel, profile,
feature evaluation or capability rerun was performed for this recommendation.
