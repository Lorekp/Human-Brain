## Failure and working hypothesis

The current pointer requires supplied document positions, resets its activations
between sequences and cannot produce general byte sequences. Older exact
assemblies replay stored atoms, but do not acquire arbitrary fresh document
values through their successful-action update API. These interface and memory
limitations hold independently of the closed reading comparison.

Test whether a learned, document-triggered synaptic writer and a learned byte
decoder can jointly retain and use new values after source removal. A small
error-correcting fast matrix is the first implementation candidate, following
[learned delta-rule memory](https://proceedings.mlr.press/v139/schlag21a/schlag21a.pdf).
The paper motivates an update rule; it does not establish prose learning or
exact-byte reconstruction at this project's scale. Representations, question
addressing and output must now be acquired through the roadmap's local online
learning rules. New-document ingestion must precede future questions and receive
no selected answer labels.

## Independent ownership and return to integration

| Lane | Deliverable | Readiness evidence |
| --- | --- | --- |
| Memory | Persistent synapses and local learning of document writing/addressing | Explicit local update factors and traces, masked no-ops, snapshot/restore, writes-disabled and recurrence controls |
| Output | Recurrent byte generation with local feedback-driven plasticity | Learned byte/EOS behavior, variable lengths, explicit EOS versus limit, deterministic restore and read-only generation |
| Integration | Raw document ingestion, saved state, fresh-process query, byte emission and existing Python motor/executor | No source/cache/autograd graph in the restarted learner; generated bytes reach real execution without a host answer-selection or formatting solver |

The memory and decoder implementations are committed with nineteen passing
focused tests. Their shared streaming rate cell, explicit state and byte/EOS
interfaces are joined in the
[source-absent development recipe](../../experiments/r4_integrated/source_absent_memory_byte_v1.md).
Disposable composition QA reproduces all eighty outputs after fresh-process
reload and preserves the shared memories. A parameter-authored decoder fixture
also reaches actual Python execution; that is transport QA, not learned output.

The forward/state components may be reused. Their differentiable interfaces and
passing numerical checks do not make their Adam-trained controller a local
learner. The withdrawn recipe already corrected a query-only training shortcut
by varying key-to-value assignments across episodes; preserve this design lesson
so the same question requires different answers from different memories.

The streaming cells now implement per-synapse forward eligibility and explicit
neuron-level updates; the byte decoder implements fixed feedback and local
readout updates. Twenty-nine focused tests pass, including ten new checks of
local arithmetic, delayed feedback, masks, frozen controls and detached restore.
These updates use no backward pass or optimizer. Their
[e-prop-inspired](https://doi.org/10.1038/s41467-020-17236-y) self-path traces and
fixed feedback approximate credit; they are not the full recurrent gradient.
The existing native three-factor readout provides a local-update precedent, but
training only an output head over fixed cells is insufficient for the intended
learned contextual representation.

Delayed feedback to document writing remains unresolved: the fast matrix's
local delta write does not teach its controller or addressing maps. The next
candidate associates each synapse's eligibility with actual neural write keys,
then uses the neural query key to select credit at feedback; the
[local writer-credit proposal](local-writer-credit.md) fixes the equations,
signal dependencies and event clocks. A single aggregate
trace can cancel opposite eligibilities from separately addressed facts.
Transport tags through the same fixed-key overwrite operation as fast memory;
this remains an approximation that omits changing-key and other indirect paths.
At current dimensions, writer/controller-map tags cost about 3.74 MB per stream,
before other state. Declare and count them after source removal. Require useful
new-value performance over a frozen-writer control, not just parameter movement.
Teacher feedback is permitted; a teacher performing inference is not learner success.

Before the next learning experiment, fix its roster, local rule, feedback,
update budget, stopping criteria and measured cost ceiling. Return to new-value,
delay, interference and real action checks after its focused test. Keep the
frozen gradient recipe separate; do not silently replace its learning rule and
reuse its admission or timing as evidence for a different experiment.

## Evidence limits

Synthetic documents and self-posed actions are engineering development tools,
not independent language evaluation. Keep their results separate from authentic
public-exam marks. General structured output must be learned; host code must not
solve option selection, table entries or event ordering and call it formatting.

Count slow parameters, persistent synapses, transient activations, optimizer
state, lexical payloads and processing costs. Snapshotting must detach and copy
the declared state: a live autograd graph can retain document-derived tensors.
Compare updating learning with its frozen mate, writes disabled and the declared
cell-controller bypass. Include an explicit retrieval-only reference before
claiming an advantage over retrieval. Exact matrix parity checks correctness;
it cannot establish an advantage over algebraically identical computation.

Neither a small fit nor a component pass establishes the integrated gate.
Return the components to the same persistent read–retain–act–learn workload,
including first attempts, later fresh tasks and old-skill retention.
