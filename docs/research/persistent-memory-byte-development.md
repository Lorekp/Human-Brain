## Failure and working hypothesis

The current pointer requires supplied document positions, resets its activations
between sequences and cannot produce general byte sequences. Older exact
assemblies replay stored atoms, but do not acquire arbitrary fresh document
values through their successful-action update API. These interface and memory
limitations hold independently of the closed reading comparison.

Test whether a learned, document-triggered synaptic writer and a learned byte
decoder can jointly retain and use new values after source removal. A small
error-correcting fast matrix is the first implementation candidate, following
[learned delta-rule memory](https://proceedings.mlr.press/v139/schlag21a/schlag21a.pdf).
The paper motivates an update rule; it does not establish prose learning or
exact-byte reconstruction at this project's scale. Representations, question
addressing and output must now be acquired through the roadmap's local online
learning rules. New-document ingestion must precede future questions and receive
no selected answer labels.

## Evidence limits

Synthetic documents and self-posed actions are engineering development tools,
not independent language evaluation. Keep their results separate from authentic
public-exam marks. General structured output must be learned; host code must not
solve option selection, table entries or event ordering and call it formatting.

Count slow parameters, persistent synapses, transient activations, optimizer
state, lexical payloads and processing costs. Snapshotting must detach and copy
the declared state: a live autograd graph can retain document-derived tensors.
Compare updating learning with its frozen mate, writes disabled and the declared
cell-controller bypass. Include an explicit retrieval-only reference before
claiming an advantage over retrieval. Exact matrix parity checks correctness;
it cannot establish an advantage over algebraically identical computation.

Neither a small fit nor a component pass establishes the integrated gate.
Return the components to the same persistent read–retain–act–learn workload,
including first attempts, later fresh tasks and old-skill retention.
