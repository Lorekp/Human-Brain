# Active-path output correction and incremental prefix simulation

Status: root-selected next implementation, 2026-09-07. The v2 broader session
is complete; this design has not been implemented or measured. It continues
the [persistent language/action plan](persistent-language-action-development-v1.md)
and the same saved neuronal model, memory and action loop. It is not a new
toy-perfection prerequisite or authorization for an epoch/gain sweep.

## Evidence and selected learning change

The [v2 learning review](persistent-language-action-v2-learning-review.md)
finds almost unchanged failed free outputs despite all 24 online B/C/U
publications. The saved teacher distributions support a more specific
observation. From `log c_s(y) = log b_s - log p_s - NLL(y)`, target-sensory
slots carry mean prior mass 0.03696 but responsibility 0.76725 over online's
98 offers. The teacher-prior winner has a different sensory symbol on 94
offers; there its mean responsibility is 0.001504 versus prior 0.006292.
This is actual teacher-prefix evidence; only position zero necessarily shares
the recorded free prefix. It is not a counterfactual decoding experiment.

The current shared U update changes an active output by
`sum_s b_s (T-z_s) <x_s,x_active>/32`. Low responsibility on the active wrong
slot alone does not prove a small total change: feature overlaps and other
current-error vectors matter. Those vectors were not saved, so the cause is
not fully identified. The selected intervention removes this particular
responsibility weighting from output correction without inventing a target
memory address.

After an actual response/action and its single declared correction, locate
the first mismatching output event against the offered raw target plus EOS.
Earlier events at that point are the learner's own correct prefix. Correct
the output cells that actually acted at that event, using the actual selected
presynaptic feature and output currents:

```
U_next = U + outer(T - z_actual, x_actual) / dot(x_actual, x_actual)
T = log(256) * onehot(current_target_token)
```

Use at most one such U correction per response. Replace the previous
all-address responsibility-weighted U updates; do not add the new clamp on
top of them. Keep the B/C local address surrogate as a separately disclosed
all-target teaching rule, with U held during its private stages. Action-head
teaching remains the existing local rule. Stage all proposals and validate
them before publication; a late failure must leave every live group intact.
Learning-disabled computes the same declared offers but publishes none.

An early EOS has a real event to correct. An extra generated byte receives
EOS as its corrective target. The terminal cap event is recorded, so it can
also be compared. An exact complete response receives no U correction.
The target cannot enter the event's earlier prefix or choose its address.
There is no alternate decoding, backward gradient, hidden repair or automatic
retry-until-success. The scalar error and own presynaptic activity are the
only plastic output inputs.

In real arithmetic this clamps that same feature's currents to T. It does
not guarantee preservation of earlier correct events, the whole sequence,
other requests, or the next selected address after B/C changes. Feature
interference and generalization remain live questions for the broader stream.

## Actual-response ownership

Retain each actual output event's detached selected feature/current, prefix,
token and address with authenticated model/memory identity. The correction
must bind to the last actual response of that same persistent reader. Extend
reading with the prediction ownership already required for actions; do not
reconstruct a more favorable response after the teacher arrives. Reject
changed features, stale state or substituted responses before publication.
Bound this trace to one pending response, and explicitly resolve teacher-free
responses before advancing. Combined action custody must still require real
execution before any correction.
Teacher-free action acknowledgement must resolve both the combined action and
the nested reader response. A corrective STOP has no payload teacher under
the existing action contract: clear its reader response with zero U/B/C offers
rather than inventing a replacement target or leaving a stale pending ticket.

Count the whole offered teacher text and all B/C symbol offers, separately
from the zero-or-one active U clamp. A reduction in output updates must not
be advertised as fewer teacher bytes when the full answer remains supplied.
Keep supervised acquisition, fresh transfer, earlier-session retention and
teacher-free recovery separate, with matched disabled and retrieval/editing
references. Preserve v2's final state and closed scores; no repeat of v2 is
fresh evidence. The tape currently occupies 505 of 512 slots, so any new
document stream needs an explicit capacity decision or must fit the remaining
space without eviction or task-selected context.

## Integral simulation improvement

The [v2 cost review](persistent-language-action-v2-cost-review.md) measures
89.917599 seconds in neuronal attempts after subtracting actual execution;
this still includes receipt conversion and state hashing. No kernel-specific
runtime attribution is claimed. Repeated prefix construction is nevertheless
an exact source-level reuse opportunity, and is selected alongside the local
credit change.

Within each call, retain the unnormalized Boolean prefix/key match activity.
Initialize the full BOS-plus-31-empty-row bank with the existing gates. Each already emitted or offered raw
byte shifts the prior query-lag rows and evaluates just one new row with the
same integer AND and match threshold cells. Recast and renormalize the full
activity bank using the original float32 operation order at every step.
Do not rescale previously normalized X or cache learned scores across updates.
All addresses remain present; free and teacher execution use the same helper.
Discard the private activity cache at call end or failed correction.

For N addresses and D decisions, prefix gate-pair evaluations become
`N*1024 + (D-1)*N*32` instead of `D*N*1024`. At N512/D17 this is a 91.18%
reduction in those evaluations, not a measured speedup. Full X scaling,
address products, competition and B/C teacher products remain. This reuse
does not itself alter output learning; the separately selected U correction
does intentionally replace all-address output-update products. Count
evaluated gates, reused activities, shift copies and held memory separately;
the cache adds 524,288 held Boolean bytes at N512.

Use ordinary affected QA for bit-exact feature/score parity of the incremental
helper under identical held weights,
actual-response binding, one-event local-clamp arithmetic and late atomic
failure. These tests support the next broader continuation; they do not
require the current task cohort to be solved or create a fitted micro-gate.
Freeze the next public stream and complete budget before running it, then
measure useful accuracy, memory and elapsed cost together.
