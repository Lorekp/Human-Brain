# Persistent language/action v4: saved learning review

Local assembly learning stores byte sequences and termination, but the learner
selects them for the wrong requests and solves none of the broader tasks. This
is progress in sequence storage, not established language understanding,
composition or useful software action. The next shared priority is learned
request/evidence routing over reusable sequence representations.

The full run and independent saved audit passed on their first launches at
released source `07ab104`: 551.3635569 seconds plus 8.827812 seconds, with sampled
serial peaks of 970.2421875 and 71.1640625 MiB. This analysis streamed the completed
attempt, teacher and empty ingest journals once, authenticated against completion
and the passed review. It used stdlib scalar operations only: no model,
checkpoint deserialization, prediction, teacher, action or alternate decoding.
The [selected plan](context-specific-sequence-assemblies-v1.md) owns the frozen
contract. All 56 episodes are now exposed development material.

## What local learning accomplished

Twelve predetermined corrections offer 223 raw bytes and twelve EOS events per
neuronal route: 235 reader offers and eighteen action labels. Every online offer
recruits and updates a new assembly. There are **235 occupied assemblies, zero
exact-context teacher reuses and zero exhaustion events**. Disabled computes 235
proposals but advances neither its private stage nor its live bank. All 277
remaining assembly slots are unused.

The local current arithmetic gives the offered token the largest current on all
235 proposals, including every EOS. Recruitment precedes the current target;
teacher prefixes appear only during correction after the actual response/action.
Updates use the selected assembly's own active presynaptic signal and current
error toward `log(256)` for the target and zero elsewhere. No backpropagation,
reverse Jacobian or all-address posterior sweep is used. These checks establish
the implemented local rule, not post-update free task success.

Online's pre-clamp teacher predictions choose the offered byte on 8/235 events,
versus 4/235 disabled. Mean teacher NLL is 6.05019 versus 6.32183. These are causal
teacher-prefix predictions before their current update, not held-out scores or
post-update probes. Across twelve corrections, online shares fourteen
actual/teacher prefix states and disabled twelve. Memory selection agrees at
every shared state. Different later prefixes remain different inputs, rather
than evidence that a teacher prefix entered the earlier free response.

## The observed selection failure

After the first response's 129 fallback decisions, all 1,950 online decisions use
learned assemblies. **None is an exact free context match.** The selected origin
has the same position on 1,175 decisions, identical preceding bytes on 885, the
same memory slot on 228 and the same reading/edit kind on 1,881. No free request
equals its selected assembly's originating request. The winning agreement ties
on 32 decisions; most wrong outputs are not tie-rule failures. Median winner
margin is eleven matching bits.

Selected patterns differ from actual inputs by 663–2,418 bits in reading and
1,336–6,351 in editing, out of 66,093. Saved totals cannot identify which field
caused the mismatch or prove that one field dominates. Every selected unit emits
its locally taught token. Across complete online responses, 47 exactly reproduce
an earlier offered target with EOS: fifteen reading and 32 editing attempts.
These are actual outputs, not counterfactual decoding. Among 65 EOS decisions,
47 have the origin's exact prefix and 64 its original output position, but only
two its memory slot.

Examples distinguish sequence recall from appropriate use:

- A02-R emits the taught `north/west` instead of `debug/audit`.
- A06-E repeats the earlier colour conditional, omitting newly required
  `str(mode).lower()` handling despite eleven correct initial bytes.
- F00-R emits `report.bak` when the request requires `blue@north`.
- Six recovery episodes emit `max(0, min(n, 3))` on all three attempts despite
  different required repairs and actual diagnostic feedback.

The source makes whole-frame Hamming similarity the fixed selection rule.
Teaching can add an exact pattern and change its outgoing byte, but cannot learn
which request tokens, file evidence or prefix relations determine relevance.
This is a concrete limitation consistent with wrong-sequence observations. It
does not prove that a different router solves composition, or that memory
retrieval and action-span learning are adequate.

## One next broader learning change

Select a **token- and field-factorized locally learned router for the existing
sequence system**, preserving learned state, raw tools and all-event byte/EOS
teaching. Its modest objective is relevant reuse across changed wording and
feedback; routing improvement must not be presented as established composition.

Generic tokenization can provide reusable symbol identities across absolute byte
positions. Field presence and ordered token/position populations should preserve
negation, order, code punctuation and diagnostic provenance. All fields remain
available: no host verb parser, chosen answer span, semantic role flag or
error-to-patch table supplies relevance. Factorization alone is not learning;
selection potentials need plastic synapses and a declared direct local teaching
signal from the already offered output events.

Define that signal in the next source/math contract before implementation. One
coherent local-credit form uses each candidate's own offered-byte likelihood to
form a responsibility and applies its scalar routing error to its own incoming
activity. This supplies neither a correct memory/assembly address nor a gradient
through a hard winner. It also has a serious ambiguity: many assemblies emit the
same byte, so next-byte evidence need not identify the relevant sequence. Prior
latent-credit failures prevent assuming this ambiguity is solved. Ordered
sequence context and candidate ownership must be explicit; hidden backward error
transport cannot fill that gap.

Evaluate the selected change in the broader persistent loop with new complete
instruction forms, longer retained context, changed requirements and teacher-free
feedback use. Keep reduced correction occasions and total target-symbol counts
separately visible. Do not require exact public-context matches, perfect old
tasks, extra epochs or an isolated routing gate first.
