# Roadmap: persistent language, knowledge and action

Status: living decision document. Updated 2026-09-07 after the user's direction
to broaden the workload. This roadmap owns priorities; frozen experiments keep
their original evidence contracts. Read it and the active linked plan before
choosing work and after every context compaction.

## Objective and current position

Build a persistent intelligence network that learns through experience, retains
knowledge, understands language, combines learned structure, acts in software
workspaces and recovers from failures. Local simulated-neuron learning and useful
real-world behavior are the central commitments.

The [third broader persistent session is complete](../../experiments/r4_integrated/persistent_language_action_v3_result.md).
Both neuronal routes score zero on acquisition first responses, fresh transfer,
delayed retention and teacher-free recovery. The simple retrieval/editing
reference scores 12/24, 6/16, 8/8 and 0/8 respectively. The same learner continues
its saved numerical model and whole 505-slot memory across 56 episodes per route;
both final states are saved. Actual-response output correction and exact prefix
activity reuse are implemented, but useful broader competence is not established.

The prepared [byte-coincidence comparison](../../experiments/r4_integrated/neuronal_splice_online_v3_result.md)
is also completed and independently audited. Its narrow successes remain
regression evidence. The [current result bank](../../benchmarks/persistent_language_action_v3.result.json)
and [learning review](persistent-language-action-v3-learning-review.md) own the
broader measurements and failure analysis.
The [experiment history](roadmap-experiment-history.md) owns chronology and retired
directions. Do not append another experiment diary to this roadmap.

## Active work: a broader persistent session

The active plan is [persistent language-and-action development](persistent-language-action-development-v1.md).
Continue the learner on a workload that combines reading,
retained knowledge, raw software actions and observation of their consequences.
Expose it to broader problems now; perfection on the current toy cohort is not
a prerequisite. All completed streams are now exposed development material.
The [current reader and local output correction](active-path-output-learning-v1.md)
are shared by reading and action payloads. It reconsiders all memory addresses
at each output step and reuses exact fixed prefix activity. Mechanics checks
pass, but useful broader answers remain unmet. The saved response and
resource reviews select the next [context-specific sequence assembly design](context-specific-sequence-assemblies-v1.md),
which combines local context recruitment with use of all already offered causal
sequence events. Longer instruction access, missing-logic software and actual
diagnostic observations belong in that same integration. This is a source-design
direction, not implemented or measured capability; another
automatic byte/operation gate or extra rounds on this exposed stream are not selected.
Continue the saved model and accumulated memory on
new instruction forms and combinations. Address selection, composition and
feedback use remain unresolved capability questions. Choose changes for this broader loop, without another
automatic operation-only or byte-only comparison.

Prioritize four pressures together:

- **Unseen instruction forms:** withhold whole instruction constructions, not
  just identifiers, paths or values. Include differences in word order and
  contextual phrasing; preserve difficult unsupported forms in the report.
- **Structural combinations:** combine learned knowledge and action requirements
  in arrangements that were not demonstrated together. Distinguish copying a
  known literal from composing a new operation or program.
- **Longer memories:** accumulate episodes on the same learner, retain earlier
  facts amid distractors and revisions, and report retention by age and memory
  load. Disclose truncation, eviction and any supplied retrieval position.
- **Reduced teacher dependence:** bound when corrective labels are available,
  then evaluate action and recovery without answer corrections. Count every
  demonstration, replay, teacher symbol and attempt.

Keep existing tasks as regression coverage, with their known failures visible.
Their original frozen scores remain unchanged. Reusing tasks for development
must be labeled exposed regression evidence, not fresh transfer. Do not turn
each residual error into an automatic isolated micro-gate or require all toy
cases to pass before broader development can run.

The prepared direct-request operation branch is source-only, unqualified work.
Its [review](neuronal-operation-intent-review-v1.md) is an input to the broader
implementation, not a separate active gate or automatic five-arm toy successor.
Retain it for review; select changes only for the shared broader workload.

## Learning and action architecture

No backpropagation, BPTT, Adam/global fitting, or manually coded reverse-Jacobian
error transport is authorized for this goal. An absence of autograd does not make
an upstream error generator local. A direct output-neuron error multiplied by
that synapse's own presynaptic activity is allowed; propagating the error backward
through earlier forward computations is not.

Use local online cell/synapse rules based on their state, pre/post activity,
eligibility and declared teaching, reward or error signals. Vectorized faithful
simulation is allowed. Keep the fixed forward computation and each signal's
source explicit. Locality alone establishes neither biological fidelity nor
understanding.

The same persistent neuronal system must learn and act. Its own learned state
chooses actions, observes their actual execution and receives any allowed local
feedback. Do not fit a separate model and transfer its answers into a nominal
neuronal executor. Source-free workers and checkpoints can establish custody;
they cannot substitute for the continual learning-and-action loop.

Tokenization and ordinary software tools may supply inputs and execute chosen
actions. They must not secretly parse the answer, choose the correct edit,
provide target memory addresses or repair the learner's proposal. Keep external
retrieval/editing references separate. Any externally supplied reasoning or
action selection is assisted-system evidence, with its contribution disclosed
and controlled; it does not establish neuron-only capability. Mem0 is external
development context and never enters model execution or scientific evidence.

## Measurements and references

Report these outcomes separately, without merging corrections into successes:

| Outcome | What counts |
| --- | --- |
| Supervised acquisition | Actual first attempts during the declared teaching schedule, subsequent improvement and total teacher exposure. |
| Fresh transfer | First attempts on held instruction forms and structural combinations, before receiving their corrections. |
| Retention | Performance on earlier knowledge and actions after intervening experience, including per-case regressions. |
| Teacher-free recovery | An initially failed task completed by the learner's own subsequent actions using permitted observations, without a correct answer/edit teacher or host repair. |

Use matched initial state, input streams, tools and action budgets for the
updating learner and learning-disabled control. State whether episodic writes
remain enabled when slow learning is disabled. Include a simple explicit
retrieval/editing reference with the same available information and tool budget;
its host computation is a baseline, not part of the neuronal learner. Add further
controls only when they answer a concrete ambiguity in the shared workload.

Separate execution success from task correctness, correct STOP from useful edits,
and successful repair from repeated identical proposals. Report failure classes
and per-stratum outcomes, not just an aggregate score. If recovery is unsupported
by the current action interface, report that limitation rather than relabeling
supervised corrections as autonomous recovery.

Public development may use deliberately varied authored exercises. Authentic
public-exam comprehension follows the [reading evaluation plan](reading-comprehension-evaluation.md)
with official questions and marking guidance; authored exercises do not replace
that evidence. Keep assessment material out of teacher selection and model tuning.

## Execution, efficiency and work selection

Build the smallest complete broader session first, then expand its language,
memory, structural and recovery demands. Use repository conventions and ordinary
affected QA from [development.md](../development.md). Freeze each measured run's
scope and resource budget, preserve failures and count the complete workload,
including references, execution, receipts and independent checking.

Use bounded public development iterations. Source review and ordinary regression
checks support integration; they are not new scientific gates. Do not silently
reuse or weaken an old frozen admission. Do not launch a succession of toy
comparisons simply because an isolated mechanism passed its checks.

Optimize measured end-to-end bottlenecks as integral code improvements. Report
useful accuracy, latency, retained bytes and work as session length grows.
Distinguish stored, active, updated and causally useful neurons. The suggested
100-billion-neuron scale is exploratory; expand when useful learning and resource
curves justify it, not to satisfy a nominal neuron count.

Delegate independent implementation, evaluation and resource work against this
one session. Review returns promptly and dispatch follow-ups that unblock it.
Repeated negative outcomes should trigger a bounded explanation/design review,
not automatic gain, epoch or seed sweeps. Keep motivation tied to learning what
works and replacing ineffective approaches.

## Longer-term progression

Broader public language/action and simple programming development proceeds now,
without a perfect-toy prerequisite. Progress toward useful Leetcode-style
problems, real repositories, knowledge revision, composition and longer plans.
General claims require fresh evidence across domains, retained skills and useful
teacher-free behavior; a literal-splice score is not that evidence.

Existing protected G0/R5/R6 cohorts and their frozen access contracts remain
separate. Broader public development does not unseal them or retroactively change
their results. Consult their actual protocols when selecting a protected run.

The long-run comparisons remain Gemma-4-12B (quantized allowed) on a fair SWE
benchmark, then Opus 4.8 on DeepSWE. Verify exact model identities, availability,
benchmark versions and matched data/tool/attempt budgets before comparison.
No such advantage has been established.
