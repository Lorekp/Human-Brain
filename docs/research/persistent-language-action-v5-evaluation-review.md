## Persistence, reference fairness and novelty

Every same-session repeat has an identical raw observation and exactly 15
intervening route attempts. Initial occupancy ranges from 556 to 731 slots; all
repeats occur at 864. Online improves one previously incorrect reading repeat,
the disabled route improves none, and the reference improves all four edit
repeats. Reference `A08-E`, for example, retrieves current demonstration 42 with
saved similarity 1.0 and one matching literal anchor, reproducing the supplied
alert implementation. This is explicitly exposed exact-query retention.

All 16 prior-regression observations per route equal the actual corresponding
v4 input records, as independently checked from the authenticated prior journal.
The first eight have 71 intervening attempts; later coverage cases have 139 or
143. Simple retains all eight previously correct cases and improves `R13-E` and
`R15-E`, which now have demonstrations acquired later in v4. The neuronal routes
compare to the same prior-online history, whose selected cases were incorrect.
Thus online's zero is continued failure, not forgetting of previously measured
success. The disabled route's four improvements (`R08-R`, `R10-R`, `R12-R`,
`R14-R`) occur without current correction updates; changed routing and ordinary
memory input remain part of its continuation. Online's failure on those same
cases is an adverse current-learning contrast, not proof that its zero prior
score was retained competence.

The reference starts with the actual 18 documents and 42 historical edit
demonstrations, then receives the same six documents and four current edit
demonstrations, ending at 24/46. It gets full requests, actual files, diagnostics
and the same tool budget. Its algorithm stores editing demonstrations but does
not store offered reading corrections. This is a disclosed difference in how
labels are used, not equal capacity between learning systems.

Saved reference attributions explain concrete limits. On `F00-R`, it retrieves
the new cache note and returns its first quoted literal `5`, missing the required
`mute:5` combination. On `F00-E`, it reuses demonstration 43's lifetime function,
missing the combined alert formatting. Historical literal reuse explains its
retention advantages; the new composition tasks remain unsolved. These examples
use saved provenance and output fields. This extraction does not independently
rerun the full trigram ranking or call the reference predictor; the prior saved
audit checks available-history and raw-query bindings.

Fresh complete requests are distinct from current acquisition and all four prior
manifests. Their maximum token Jaccard overlap against exposed requests ranges
from 0.1875 to 0.32. Those values and construction labels do not establish whole
linguistic-family holdout. The fresh tasks combine familiar facts and code
primitives with formatting, selection, filtering, aggregation and bounds. Two
complete observed program snippets supply `initials` and `bounded`; successful
reuse of them would not be invention from no example. The cache note's word
“now” alone also does not establish a tested conflicting-belief revision.

## Exposure, resources and evidence limits

The same persistent actor handles reading and editing, with no backpropagation,
separate solver or target-selected memory. Both neuronal routes preserve the
initial 505 occupied fact slots and append 353 complete raw source bytes plus six
EOS, ending at 864 under capacity 1024. The disabled route disables current
correction plasticity while retaining the same factual association writes.

Eight corrections per neuronal route offer 155 target bytes plus eight EOS =
163 external events and 12 action labels. Routing and assembly output each use
those same events; their internal uses are not two external teacher passes.
Compared with v4, both occasions (12 to eight) and symbols (235 to 163) decrease,
but no useful fresh capability accompanies that reduction. Source observation,
ordinary association writes, diagnostics and inherited demonstrations remain
separate information sources. The complete session records 240 attempts,
156 children, 24 correction rows and 18 document appends across all routes.

The run takes 558.5371355 seconds with a 723.078125 MiB measured peak; the saved
audit takes 8.3754013 seconds and 102.6640625 MiB. Combined wall time is
566.9125368 seconds, within the selected 900-second/2048-MiB envelope. The
additional saved evaluation extraction takes 3.2096472 seconds and succeeds on
its first execution, with no model construction, checkpoint decoding, prediction,
