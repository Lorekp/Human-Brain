All eight recovery issues fail initially and on their final third attempt in
each route. No transient successful retry is concealed. Neither core consumes
the recorded tool feedback; unchanged repetitions cannot establish an ability
to learn from errors. This is a visible limitation, not a failed recovery rule
that was actually implemented and tested.

The two neuronal routes begin with identical numerical state from the disclosed
trained v3 coincidence learner, not fresh weights. Both see the same incrementally
appended sixteen documents, 437 raw bytes plus sixteen EOS slots, on one shared
453-slot state. Online weights change through the declared corrections; the
disabled route retains its slow weights. There is no exact-score benefit from
those changes in this one-pass session. This is not evidence that local learning
can never help or that stored information is wholly absent.

The simple route accepts the full four over-capacity requests, whereas both
neuronal routes explicitly reject them. Report the access/capacity difference:
on the common twelve fresh items at most 31 bytes long, the reference still
gets 6/12 (5/6 reading and 1/6 editing), versus 0/12 in both neuronal routes.
It solves three of four long-request challenges. Thus request capacity explains
part of the overall comparison, but cannot explain the supported-subset failure.

Delayed results revisit exposed acquisition observations after intervening work.
The initial comparison point is the acquisition **first response**, before its
correction, not an immediate post-teacher mastery test. Zero delayed neuronal
answers therefore does not establish eight measured forgetting events. The
reference preserves four initially correct reading answers and improves its four
revisited edits after receiving their demonstrations. Project files reset at
each episode; only retries continue their resulting workspace. Persistence is
of learned/episodic state, not one continuously modified repository.

## Reference attribution

Independent checks cover all 72 saved reference attempts and the chronological
availability of its documents and twelve supervised edit demonstrations:

- Every retrieved document was already appended. Recomputed raw-query trigram
  similarity confirms its recorded choice and tie order. The answer bytes match
  the first boundary-delimited quoted literal in that document, with the saved
  source hash and byte span. Possessive apostrophes do not masquerade as openers.
- Every reused edit refers to an earlier, actually offered acquisition correction.
  The teacher row binds the preceding actual attempt's hash. Its source bytes,
  query hash, old literal anchor and replacement match the recorded demonstration.
  The saved action follows the unique occurrence of that old literal in the
  actual current files, or STOPs when there is no unique application.
- No prediction needs an episode ID, private grading field, future document or
  future demonstration. The first edit has no demonstration and explicitly
  emits STOP. Reading uses the documents rather than a table of taught answers.

These are transparent conventional references. Their quoted-literal extraction
and raw-anchor editing are host algorithms, not neural understanding. They are
strong enough to show that useful information and some reusable corrections
are available in this stream, while failing composition and all eight recovery
issues. Their success does not warrant embedding their answers in the neuronal
core and relabeling that as learned comprehension.

## What is fresh, and what the score measures

There are no identical acquisition requests in the sixteen fresh items. The
new action placements include list indexing, dictionary lookup, a conditional
expression and a call argument, which were not acquisition structures. However,
twelve items share a broad question/imperative family with acquisition, and one
shares its exact author-assigned construction label. Maximum token-set overlap
with an acquisition request ranges from 0.125 to 0.4444, with median 0.2222.
These labels and lexical figures describe overlap; they do not prove independent
linguistic coverage or generalization. This is a small agent-authored public
development stream, not authentic official-exam or protected evidence.

The supported exception/contrast item, “In tests, colour; otherwise?”, requires
combining the testing and production notes into “green; blue”. It fails in all
routes. This exposes a real composition demand within the short-input boundary;
the rest of the reading subset remains predominantly single-literal retrieval.

Reading success is frozen exact-byte agreement. That criterion also tests answer
boundaries and formatting. For example, a response containing the prose fragment
“badge is 'blue'” contains relevant information but is not the requested exact
`blue` response. A separate descriptive substring check finds the expected bytes
inside 8/22 supported first reading outputs in each neuronal route: 5/13
nonnumeric targets and 3/9 numeric targets. This is **not semantic credit**:
digits can match incidentally, and inclusion does not establish a correctly
scoped or complete answer. The exact scores remain zero. Conversely, zero exact
scores alone must not be described as zero knowledge retrieval.

Editing is behavior-scored after real execution, with protected-main integrity;
an alternate correct patch is accepted. It does not require the canonical byte
patch. The [learning review](persistent-language-action-v1-learning-review.md)
finds all thirty supported first edit payloads wrong, while the online operation
choice matches the canonical operation on 29/30. This broader failure is not the
previous toy cohort's operation-choice bottleneck.

## One next broader pressure

Coordinate the next architectural choice around **request-conditioned answer
construction and stopping, shared by language responses and action payloads**.
The current cursor copies a document suffix through document EOS; correct
retrieval can still overrun the requested answer, and combining two notes cannot
be achieved by copying one contiguous suffix. The existing codec does not make
its token distribution directly conditional on the current request. These are
source-level limitations and observed response patterns, not proof that one
particular new circuit will solve the stream.

Keep the next integration pressure broad: short factual answers, a bounded
condition/exception relation, a two-note answer and executable uses in different
code positions, alongside delayed retention and openly reported recovery. Use
fresh instances/forms and matched disabled/reference access when root selects
the successor. Keep teacher exposure bounded. Do not return to another
operation-only toy comparison, add rounds until these answers are memorized,
strip quotes with a hidden host answer parser, or supply a correct source span.
Any proposed local circuit must produce its answer and action in the same
persistent learner without reverse-Jacobian error transport. A feedback-aware
claim must actually expose public outcomes to that computation; until then,
retain the honest zero-recovery limitation.

This recommendation is a shared source/math priority with the learning reviewer,
not a new fit, implementation or evaluation authorization. The broader stream
has already done useful work by distinguishing storage, answer packaging,
composition and recovery limitations without demanding old-toy perfection.
