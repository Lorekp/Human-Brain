## Budget judgment

An840second runner plus60second saved-review reservation under2048MiB is a
plausible bounded attempt, not a validated time projection. Fixed tensor and
block sizes leave substantial nominal memory space, but cannot bound allocator,
reference-history parsing or all process overhead. Runtime risk is material:
long generated prefixes multiply dense address work, complete input agreement,
full-bank validation and hashing; enlarged action heads add substantial products.
At144children*3seconds, child timeout allowances alone can consume432seconds,
before termination/capture cleanup. The840second outer watchdog must remain
authoritative even inside a long teacher or child-cleanup operation. Source
checks between attempts cannot alone guarantee total completion by the limit.

Proceed only as the one selected broader measured continuation with its hard
outer guard and reserved saved check. A timeout is a preserved incomplete result,
not grounds for an identical retry or a hidden smaller exposure. There is no
additional isolated cost gate, simulated throughput estimate or success forecast
in this note. After completion, report run plus review elapsed, maximum owned
tree memory, actual children/decisions/occupancies, source/hash traffic and
stage totals separately from capability.
