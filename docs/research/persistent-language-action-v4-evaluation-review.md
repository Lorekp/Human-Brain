## What is new, and what is exposed

The 48 new requests are 117–168 raw bytes, compared with the previous 31-byte
action-request limit. The interface now accepts 256 request bytes, four files of
512 bytes, 128 output bytes, and 512 raw bytes for each actual diagnostic stream.
The eight old retention requests stay exact and short. This session has no
deliberately over-capacity initial request stratum.

Fresh tasks withhold complete multiclause requests and combine requirements in
new ways: negation and exceptions, ordered factual composition, list filtering,
dictionary construction, independent conditions and filename transformations.
The facts and many words remain exposed. No fresh request exactly repeats the
three previous sessions or current acquisition. The manifest's maximum token-set
Jaccard overlap with that history ranges from 0.15625 to about 0.32353. This is a
lexical disclosure, not a measure of semantic novelty. Construction labels are
author judgments; there is **no whole-family holdout claim**, protected benchmark
or official-exam claim.

Programs initially lack the required expressions. Their public drivers exercise
multiple inputs, including negative counts, empty collections and filenames,
case variants and missing values. Grading checks actual stdout, return status,
complete execution and unchanged protected `main.py`; it does not demand the
canonical patch. This distinction matters: a runnable but wrong program and an
edit to the protected driver both fail even when an output fragment looks useful.

Across the 32 first editing attempts per route, the online route has 19 runtime
failures, eight protected-file changes, three LIMIT rejections and two wrong
stdout results. Learning disabled has 28 LIMIT rejections, two runtime failures,
one protected-file change and one wrong stdout result. These are exclusive
descriptive categories, assigning protected-file failure before runtime failure;
they do not isolate causal contributions of payload, location and operation.
The online route changes action behavior substantially without solving a task.

## Next broader learning opportunity

Keep the exact old regressions and sustained memory, but make the next public
continuation expose learning opportunities along a meaningful progression:
single missing expressions, related paraphrases and input variations, then
combinations and actual diagnostic repairs. Include some exact-context delayed
revisits alongside unseen forms so retention of an offered sequence and transfer
to new structure can be distinguished. Interleave these with unsolved broader
tasks; do not require perfect toy performance or remove difficult failures.

Fix correction occasions and symbol budget before observing outputs. Place
related uncorrected requests later in the stream, and score first responses,
teacher-free recovery and delayed retention separately. Existing project damage
must continue honestly; separately started projects can provide independent
transfer observations without repairing a live chain. Public feedback remains
the only recovery signal. This is a workload recommendation, not evidence that
the current assemblies can generalize, an endpoint-specific repair, or a selected
new implementation. A memorized teacher string alone would not satisfy the
required novel behavioral inputs and compositions.
